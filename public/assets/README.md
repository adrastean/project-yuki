# Optional avatar / İsteğe bağlı avatar

Yuki does not include a redistributable avatar model. To enable the avatar panel, place a VRM model that you created or are allowed to redistribute at `public/assets/yuki.vrm`.

Yuki dağıtım izni olan bir avatar modeli içermez. Avatar panelini kullanmak için kendi oluşturduğun veya yeniden dağıtım iznin bulunan bir VRM modelini `public/assets/yuki.vrm` konumuna yerleştir.

The `.gitignore` excludes this path so a private or unlicensed model is not committed by accident. Confirm the model's license before sharing a build that includes it.

Bu dosya yolu `.gitignore` ile dışarıda bırakılır; özel veya lisanssız bir model yanlışlıkla depoya eklenmez. Model içeren bir derlemeyi paylaşmadan önce lisansını kontrol et.
